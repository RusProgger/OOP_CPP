# OOP_CPP

A personal learning repository focused on **Object-Oriented Programming (OOP) in C++**.

## About

This repository contains my exercises, practice tasks, experiments, and small programs created while learning C++ and Object-Oriented Programming.

The purpose is not to build production-ready software, but to understand how OOP works in practice and develop a stronger understanding of C++.

## What I'm Learning

* Classes and Objects
* Encapsulation
* Access Modifiers
* Getters and Setters
* Constructors and Destructors
* Inheritance
* Polymorphism
* Abstraction
* Virtual Functions
* Composition
* References and Pointers
* Dynamic Memory Management
* Smart Pointers

## Approach

I learn each concept by writing code and experimenting with it rather than only studying theory.

The repository will grow gradually as I learn new concepts and gain more experience with C++.

## Goal

The main goal is to build a solid understanding of OOP principles and learn how to apply them effectively in C++.

## Status

🚧 **Learning in progress**

This repository is actively updated as I continue learning and practicing C++.

> Learning by doing, one concept at a time.
